# NEXTGEN DIGITAL

Sitio web estático para NEXTGEN DIGITAL.

## 🌐 **Despliegue**

Este proyecto está desplegado en:
- **Vercel**: https://nextgen-digital-m34ats6kd-samuels-projects-9f7e4de3.vercel.app
- **GitHub**: https://github.com/Gutierrez20204/NEXTGEN-DIGITAL.git

## 🔄 **Despliegue Automático**

El sitio se despliega automáticamente cada vez que se hace push a la rama `main` de GitHub.

## 📁 **Estructura del Proyecto**

- `index.html` - Página principal
- `css/` - Archivos de estilos
- `js/` - Archivos JavaScript
- `images/` - Imágenes del sitio

## 🚀 **Desarrollo Local**

Para probar el sitio localmente, simplemente abre `index.html` en tu navegador o usa un servidor local.

## 📝 **Actualizaciones**

Para actualizar el sitio:
1. Haz cambios en los archivos
2. `git add .`
3. `git commit -m "Descripción de cambios"`
4. `git push`
5. Vercel se desplegará automáticamente

## ⚙️ **Configuración**

- **Netlify**: Configurado con `netlify.toml`
- **Vercel**: Configurado con `vercel.json`
- **Git**: Control de versiones con GitHub
