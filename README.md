# NEXTGEN DIGITAL

Sitio web estático para NEXTGEN DIGITAL.

## Estructura del Proyecto

- `index.html` - Página principal
- `css/` - Archivos de estilos
- `js/` - Archivos JavaScript
- `images/` - Imágenes del sitio

## Despliegue en Netlify

Este proyecto está configurado para ser desplegado en Netlify.

### Opciones de Despliegue:

1. **Drag & Drop**: Arrastra la carpeta del proyecto a netlify.com
2. **GitHub**: Conecta tu repositorio de GitHub
3. **CLI de Netlify**: Usa el comando `netlify deploy`

## Desarrollo Local

Para probar el sitio localmente, simplemente abre `index.html` en tu navegador o usa un servidor local.
